# 即刻账号分析工具

一个用于演示“账号内容分析 + 关键词筛选”的纯前端静态页面。项目使用
HTML、CSS 和 JavaScript 构建，不需要安装依赖或编译。

> 当前版本使用模拟账号和模拟内容数据。它不会绕过即刻的跨域限制，也不会
> 抓取真实账号内容；飞书同步同样为界面演示，不会向飞书写入数据。

## 功能

- 输入账号链接并生成演示分析结果
- 按一个或多个关键词筛选内容
- 只显示匹配项、排序和高亮关键词
- 在浏览器本地保存最近一次分析历史
- 提供主应用页和介绍页两套静态入口

## 本地运行

直接打开 `index.html` 可以查看主应用；部分浏览器对本地文件限制更严格，
推荐使用静态服务器：

```bash
python3 -m http.server 8000
```

然后访问：

- `http://127.0.0.1:8000/`：主应用
- `http://127.0.0.1:8000/landing.html`：项目介绍页

## 使用流程

1. 在“博主账号链接”中输入一个链接。
2. 输入一个或多个关键词，使用逗号分隔。
3. 点击“开始分析”。
4. 使用筛选、排序和关键词高亮查看演示结果。

分析历史和飞书配置保存在当前浏览器的 `localStorage` 中，可在页面中清除。

## 项目结构

```text
.

│   ├── style.css     # 主应用样式
│   ├── nav.css       # 导航样式
│   └── landing.css   # 介绍页样式
└── js/
    ├── app.js        # 筛选、排序和演示数据逻辑
    └── landing.js    # 介绍页交互
```

## 技术限制

浏览器的同源策略会阻止页面直接读取即刻数据。要接入真实数据，需要合法的
后端代理、官方授权接口或浏览器扩展能力，并遵守平台服务条款和访问频率限制。
